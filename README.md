# 🌌 Etherana SX

**Etherana SX** is a premium, AI-powered answering engine designed specifically for solo entrepreneurs. It reimagines web search as a structured productivity hub, transforming raw information into specialized business outputs.

![Etherana SX Welcome](/Etherana_SX_Welcome.png)

## 🚀 The Solo Entrepreneur Suite

Etherana SX is organized into three core pillars designed to support the entire business lifecycle:

### 🏙️ Spaces (Organization)
Stop losing track of your research. Organize your conversations and files into dedicated work environments.
- **Operations**: Manage day-to-day tasks and SOPs.
- **Sales & Marketing**: Track leads and build brand awareness.
- **Client Work**: Dedicated areas for project delivery.
- **Custom Instructions**: Each Space can have its own AI behavioral settings.

### ✅ Tasks (Momentum)
A recurring task system that acts as your lightweight business assistant.
- **Daily Focus**: AI-powered priority setting every morning.
- **Weekly Strategy**: Monday morning planning sessions.
- **Proactive Follow-ups**: Automated checks for client and sales engagement.
- **Business Reviews**: High-level health checks for your solo venture.

### 🧪 Labs (Output)
The experimental workbench where ideas become professional results.
- **Reports**: Generate deep-dive business analysis PDFs.
- **Data**: Structure raw info into clean spreadsheets (CSV).
- **Presentations**: Convert notes into structured slide deck outlines.
- **Web Apps**: Prototype simple functional tools and landing pages.

## 🛠️ Key Features

- **Multi-Source Research**: Searches across the web, your files, and past conversations.
- **Context-Aware AI**: Powered by advanced LLMs with specialized internal personas.
- **Privacy First**: Designed for private, solo use with local-first data principles.
- **Premium UI**: Dark mode, glassmorphism, and smooth animations for a state-of-the-art experience.

## 📦 Installation

### Prerequisites
- Node.js 18+
- SQLite3
- Docker (optional)

### Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/GoAnon/Etherana-SX.git
   cd Etherana-SX
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Access the setup wizard at `http://localhost:3000`.

### Docker Setup
1. Build and run via Docker Compose:
   ```bash
   docker-compose up -d
   ```
2. Access the app at `http://localhost:1414`.
